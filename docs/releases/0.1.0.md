# Omarchy Replay 0.1.0

First public release · September 26, 2026.

Find things you saw on your screen. Omarchy Replay keeps local screen history with a keyboard-driven timeline, text search and the original images.

[Watch the 15-second launch video](https://youtu.be/F9FaIxpPdvo).

## Included

- Background recording of one selected display, with separate capture and indexing controls.
- Local OCR, partial-word search, matching-line highlights and copy, plus drag-to-copy text from saved images.
- A floating viewer, keyboard navigation and top-bar controls for history, settings and recording.
- Rolling retention by age and disk allowance, configurable local storage and OCR resource settings.
- Capture checks for lock, sleep, display availability and excluded windows.
- Optional completed-meeting search through the separate [Omarchy Meeting Recorder](https://github.com/jankeesvw/omarchy-meeting-recorder) plugin, grouped by meeting with known starts on the timeline.
- Copyable prompts that help an installed coding agent configure and diagnose Replay without a development checkout.

## Set up

This release targets Omarchy's Lua-based Hyprland configuration. Follow the [installation guide](https://github.com/rblalock/omarchy-replay/blob/v0.1.0/docs/installation.md) and install the [documented system dependencies](https://github.com/rblalock/omarchy-replay/blob/v0.1.0/README.md#source-installation-and-development), then:

```bash
omarchy plugin add https://github.com/rblalock/omarchy-replay.git --enable
```

Choose **Set up Replay** from its top-bar menu. Setup builds the native app locally; it does not install system packages. Fresh installation leaves recording and login startup off. Choose a display in Settings, then start recording. **Super+Alt+R** summons or dismisses the viewer when the shortcut is available.

Plugin updates and native updates are separate: after updating the plugin, use **Update Replay** or the manual update command in the installation guide.

## Your data

Images, OCR and imported transcripts stay in the configured local archive. Defaults are five-second captures, a 30-day age limit, a 10 GiB rolling allowance and 1 GiB left free. Actual retained history depends on workload and both storage limits. Closing the viewer leaves background recording unchanged.

Privacy exclusions mask matching windows in ordinary screenshots and screen sharing too. **Skip in Replay** only pauses Replay capture. Review these settings before recording. Meeting integration is off by default; the external recorder owns audio and transcription. Replay does not start call recording or modify its original files.

## Remove

Close Replay's viewer windows, then remove the native app before the shell plugin:

```bash
~/.local/bin/omarchy-replay uninstall
omarchy plugin remove io.github.rblalock.omarchy-replay
```

This preserves settings, history and diagnostics, and saves recording as stopped. Removing only the bar plugin leaves the native app installed.

## Current limits

This is early software for everyday testing. It records one display; OCR can miss or misread text, and sampling misses content between captures. Resource settings control OCR but do not cap the whole application's CPU use. Hardware lifecycle behavior and performance vary by machine.

Meeting anchors identify the call's start, not the exact screenshot for each sentence. Unknown dates stay unanchored. Meeting search is in the viewer; the existing CLI searches screen OCR only. Dedicated agent recall, semantic search and remote storage remain planned.
